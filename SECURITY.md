# SECURITY POLICY

## Reporting Security Issues

We take the security and integrity of this project very seriously. Because only the original author manages these APIs, any unauthorized tampering, malicious modification, or distribution of altered files is strictly prohibited.

If you discover any security vulnerabilities or misuse of these public APIs:
* **Do not** disclose them publicly before they are addressed.
* Contact the maintainer directly via GitHub profile: [markelcanton](https://github.com/markelcanton/).

Thank you for helping keep this project secure.
